# Pass by Reference in C

This program demonstrates passing the address of a variable to a function.
The function can directly modify the original value using a pointer.

## File

pass_by_reference.c

## Concepts Used

- Function arguments
- Function parameters
- Pointers
- Pass by reference
- Address operator

## How to Run

gcc pass_by_reference.c -o pass_by_reference
./pass_by_reference

## Sample Output

Before function call: 50
After function call: 100
